# 访问数据看板

后台概览页提供 7、30、90 天三个时间范围：

- 累计独立访问；
- 范围内独立访问、请求数和刷新数；
- 每日独立访问趋势；
- 首次访问小时热力图；
- 来源站点、热门路径、浏览器和设备排行。

## 统计口径

- `独立访问`：同一加盐 IP 指纹在 `VISITOR_UNIQUE_WINDOW` 内计一次；
- `请求`：该窗口内主页及公开详情请求总数；
- `刷新`：请求数减去独立访问数；
- 来源、页面、浏览器与设备排行按独立访问日志条数聚合，而非请求次数。

数据仅来自自建 `visit_log` 表，不加载第三方统计脚本。Referer 只保留站点 origin，User-Agent 只保留浏览器、系统和设备类型。日志超过 `VISITOR_LOG_RETENTION` 后自动删除，但历史累计访问数不减少。

聚合接口：`GET /api/admin/analytics?days=7|30|90`，受后台 Bearer token 保护。
