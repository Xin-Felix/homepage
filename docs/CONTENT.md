# 内容管理

## 默认内容与升级

- `backend/src/main/resources/db/homepage-seed.sql` 是新数据库的主页默认内容，包含 Profile、经历、项目卡片、项目 Markdown 和联系方式；
- backend 在 Hibernate 建表后检查 `profile.id=1`，只有全新数据库才执行完整 seed；
- `db/content-updates/` 保存已有库的一次性内容更新，每条 SQL 都带旧默认值条件，后台已编辑的字段不会被覆盖；
- 默认 SQL 不会重置访问数、排序、显隐、发布状态或管理员数据；
- 默认技术笔记仍由 `NoteInitializer` 在笔记表为空时创建；当前 SQL 会幂等加入真实的“穿搭同款搜索系统”和 Ying+ AI 内容工程案例，不生成虚构内容。

线上更新前仍应按部署文档备份 MySQL。后续日常内容维护统一使用管理后台，不直接修改 SQL。

## 项目案例

后台进入“开源与项目”，每个项目同时包含首页卡片和可选详情页。

| 字段 | 说明 |
|---|---|
| 项目名称 | 首页及详情页标题 |
| 详情路径 | URL slug，例如 `product-migration`，只能使用小写字母、数字和连字符 |
| 外部链接 | GitHub 或在线演示，可留空 |
| 卡片摘要 | 首页卡片和 SEO 摘要 |
| 我的角色 / 项目时间 | 详情页元信息 |
| 卡片标签 | 逗号分隔，最多 8 个 |
| 案例详情 | Markdown 正文，最多 50000 字 |
| 发布案例详情 | 开启后 `/projects/{slug}` 才可访问 |
| 在主页显示 | 控制首页卡片；隐藏后详情也不公开 |

发布详情前必须同时填写 slug 和 Markdown。slug 全站唯一，重复保存返回 HTTP 409。

## Markdown 支持

支持标题、段落、有序/无序列表、引用、粗体、斜体、删除线、代码块、表格和 http/https/mailto 链接。后台“预览 Markdown”与公开详情页使用相同渲染器。

Markdown 先由 `marked` 解析，再由 `sanitize-html` 白名单清洗。脚本、事件属性、`javascript:` URL 和任意 HTML 不会进入页面。

## 发布流程

1. 新建项目并填写首页卡片信息；
2. 保持“发布案例详情”关闭，编写 Markdown 草稿；
3. 使用后台预览检查排版；
4. 填写唯一 slug；
5. 开启发布并保存；
6. 从首页卡片或 `/projects/{slug}` 验证。

## 技术笔记

后台“技术笔记”支持标题、slug、摘要、标签、Markdown 正文和发布状态。草稿只在后台可见；发布时自动记录发布时间，再次从草稿发布会更新发布时间。

公开路由：

- `/notes`：已发布笔记列表；
- `/notes/{slug}`：笔记详情并增加阅读量。

编辑流程与项目案例一致，可使用“预览 Markdown”检查最终安全渲染结果。删除笔记不可恢复，临时下线应取消“公开发布”。

## AI Lab

后台 AI Lab 始终可见，公开主页、导航和 `/ai` 入口只有存在“公开发布”的项目时才出现。当前默认 SQL 会加入真实的“穿搭同款搜索系统”案例；后续项目仍需在后台编辑并显式发布，系统不会生成虚构内容。

字段包括：项目名称、slug、摘要、状态、模型/服务、技术栈、演示地址、仓库地址和 Markdown 详情。状态可选：

- `IDEA`：构思中；
- `BUILDING`：开发中；
- `LIVE`：已上线；
- `ARCHIVED`：已归档。

公开发布前必须填写 slug 和 Markdown 正文。推荐先保存为未公开状态，完成预览和链接检查后再发布。

## 中英文双语

站点支持访客切换中英文，面向海外机会。中文是权威内容，英文为可选翻译；**任何英文字段留空时，前台自动回退显示中文**，不会出现空白。

### 数据如何存

每张内容表都新增了与中文字段对应的英文列（如 `name_en`、`description_en`、`content_markdown_en`、`tags_en` 等）。slug、外部链接、状态、布尔开关等语言无关字段中英文共用，不重复。

### 在哪里维护英文

后台每个内容表单在中文字段下方都有对应的「（EN）」英文输入框，直接双份编辑即可：

- 基本信息：名字、标题、问候语、一句话介绍、技能标签、关于我、SEO 描述/关键词、页脚；
- 工作经历：时间、职位、公司、描述；
- 项目：名称、卡片摘要、角色、时间、卡片标签、案例详情 Markdown；
- 技术笔记：标题、摘要、标签、正文 Markdown；
- AI Lab：名称、摘要、模型/服务、技术栈、详情 Markdown；
- 联系方式：名称、显示文字。

英文初稿已通过 `db/content-updates/2026-10-english-core-fields.sql` 和 `2026-10-english-markdown.sql` 幂等写入（仅在英文列为空时写入，不覆盖后台已编辑的英文）。在后台校对润色后，这些脚本不会再覆盖你的修改。

### 访客如何切换

- 英文站使用 `/en` 前缀：`/en`、`/en/projects/{slug}`、`/en/ai`、`/en/notes/{slug}` 等；中文站保持原路径；
- 页头和详情页都有语言开关（中文 / English），点击跳转到当前页面的另一语言版本，并记住选择；
- 首次访问时按浏览器语言自动选择（浏览器主语言为中文→中文，其余→英文），仅在客户端生效，不影响爬虫看到的中文默认页；
- SEO 上中英文互为 `hreflang` 对应版本，`x-default` 指向中文；sitemap 同时收录中英文 URL；`<html lang>` 与 Open Graph `og:locale` 按语言切换。

### 新增内容时

通过后台新增项目/笔记/AI 项目时，填好中文后在对应「（EN）」字段补上英文即可，无需改任何代码或 SQL。暂时没空翻译时留空，前台会显示中文。
